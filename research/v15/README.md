# V1.5 统一统计与校正记录

统计截止：2025、2026年均为1月1日至11月25日。主要案件名录采用已归档的麦家星球完整年度明细；WorldTRO用于同案信息和权利类型线索核对。覆盖范围不同的列表不直接相加。

- 同期总量：2025年2,273件；2026年2,969件；增加696件，增长30.6%。
- 伊利诺伊北区：2,044→2,344；其他地区229→625。外围净增量396件，占总净增量56.9%。
- 当前占比：伊利诺伊北区79.0%，上年同期89.9%；下降11.0个百分点。
- 2026年明确版权线索及具体版权案由共识别628件，专利相关94件。其余2,247件包含商标及未明确分类案件。主报告不对分类覆盖不同的两年计算版权增速，撤下旧49.6%判断。
- WorldTRO读取2,100行列表，包含重复50行；去重后2,050条，其中244条未与既有名录的州+案号匹配。保留差异供核对，未在只有近期较充分覆盖的情况下单边增加2026年的分母。
- WorldTRO公开页面脚本公布的分类辅助接口按裸案号返回案由。对跨法院同号记录不直接应用辅助分类；840的历史默认值与版权名称存在明显冲突，未用其推定全部剩余记录为商标。名称明确的版权/专利线索优先于冲突默认类型。
- 法院+案号为去重键。2条纽约杂项程序记录原解析法院为空，已由原始URL恢复nysd；田纳西记录州字段由法院tnmd恢复TN。5242条同期记录全部映射至22个法院地区。
- 2025年第四季度及2026年第四季度均截至11月25日；不同长度季度不作环比趋势推断。
