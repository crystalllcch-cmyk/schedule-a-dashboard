# Data files

- `dashboard.json`: verified FJC R24 v3 candidate aggregates, district aggregates, candidate-group aggregates, NOS counts, and source registry.
- `district_quarterly.json`: district-quarter summary extracted from the R24 regional summary file. Its totals differ from the case-level candidate file by 9 records across six quarters; see `../docs/METHODOLOGY.md`.

Full case-level records are intentionally not included in this initial prototype. The Cases page does not fabricate sample records; full candidate-detail import remains a separate task.
