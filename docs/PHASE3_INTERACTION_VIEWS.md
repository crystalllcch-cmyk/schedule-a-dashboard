# 第三阶段：高级交互与多视图（2026-11-23）

## 本阶段新增
1. 地域视图：地图视图 / 结构化列表切换。两种视图共用立案年份、巡回区、地区和NOS筛选。列表显示当前筛选口径下的地区候选记录数量；点击地区行可将地区筛选定位到该地区并切回地图。
2. 案件档案：档案列表 / 案件星图切换。星图仅展示当前档案筛选命中的精选案件；横轴为档案日期、纵轴为巡回区，点形状区分判例效力类型。
3. 星图下钻：点击节点后重置其他档案筛选条件、按案号定位对应档案、展开详情并滚动至详情位置。
4. 地图和列表沿用同一份FJC候选数据与现有筛选函数；案件星图沿用26份精选档案及原有独立档案筛选。没有把不同统计总体合并。

## 修改文件
- `index.html`：地域视图切换控件、结构化列表容器、案件星图容器与响应式样式。
- `app.js`：地区列表生成、视图切换、案件星图绘制、节点下钻、筛选后星图同步。
- `scripts/verify_interactions.cjs`：增加地图/列表、档案列表/星图切换断言。
