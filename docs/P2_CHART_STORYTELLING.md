# P2 · 图表叙事与动态分析系统

日期：2026-11-24  
工作分支：`feature/p1-content-storytelling-2026-11-24`  
基于P1信息架构继续开发；不修改V0.8正式版本。

## 一、目标

让图表不再只是数值展示。用户通过悬停/触摸获得即时解释，通过点击数据点打开完整分析；筛选变化时，图表和对应文字同步更新。

## 二、已完成的交互架构

### 1. 统一分析抽屉
- 桌面端从右侧展开，宽度540px。
- 手机端从底部展开，宽度适配屏幕，测试视口下宽390px、高约709px。
- 支持关闭按钮、Escape关闭、焦点恢复。
- 打开时隐藏图表悬停提示，避免提示框遮挡分析内容。
- 面板内容分为核心发现、数据拆解、研究解释、业务观察、同期司法事件和研究来源。

### 2. 动态文字分析
- 趋势：随年份/季度/地区/巡回区/NOS筛选更新当前总量及最高候选季度。
- 地域：更新当前筛选下数量最高地区、占比及前三地区合计。
- NOS：更新当前筛选下主要诉讼性质分类及数量。
- 首页KPI保持全候选池固定基准，不随局部筛选变化。
- TFL/ABTL样本、110条抽样质量和案件档案保持独立统计范围。

### 3. 图表悬停解释
- 月度、季度、半年度：显示前期变化和同期司法事件入口。
- 地区：显示当前筛选占比及地区分析提示。
- NOS：显示当前筛选占比和行政分类解释。
- 品牌：显示品牌月均速度及样本提示。
- ABTL：提示2025年数据截至11月11日。
- 其他程序结果图表通过点击分析面板展示其分母、分类含义及适用限制。

### 4. 已绑定深度分析的图表
首页趋势、月度、季度、半年度、地区排名、NOS构成、非NDIL权利结构、最新状态、DISP结案方式、NOJ判决子集、Precision、TFL品牌年度、品牌分项、ABTL历史序列等主要图表。

趋势点击后自动匹配相同月份、季度或半年度内已收录的精选司法事件；没有收录事件时明确说明，不把“未收录”解释为“没有事件”。

## 三、数据与分析口径

- 趋势比较在相同地区、巡回区和NOS条件下进行。
- 半年度图表使用固定比较期间；年份/季度筛选不改变半年度比较窗口。
- 地区详情使用当前筛选统计，并另列固定H1对比。
- NOS是FJC行政诉讼性质分类，不等于法院最终认定的实体侵权类型。
- DISP反映案件终结方式，不直接等于TRO/PI申请结果。
- NOJ图表只适用于对应判决类别子集，不解释为全部案件胜诉率。
- Precision仅是4,551条候选池内部识别精度，不代表全国识别率或召回率。
- 品牌样本与FJC候选池不合并。

## 四、独立HTML构建
